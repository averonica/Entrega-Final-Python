# Sistema de Gestión de Inventario

Proyecto final desarrollado en Python utilizando SQLite como base de datos.

## Descripción

Este sistema permite administrar un inventario de productos desde la consola mediante un menú interactivo. Los datos se almacenan de forma persistente en una base de datos SQLite.

## Funcionalidades

- Agregar productos.
- Mostrar todos los productos.
- Buscar productos por ID.
- Actualizar productos.
- Eliminar productos.
- Generar un reporte de productos con stock bajo.
- Creación automática de la base de datos y la tabla si no existen.
- Carga de productos de ejemplo al iniciar el sistema por primera vez.

## Tecnologías utilizadas

- Python 3
- SQLite3
